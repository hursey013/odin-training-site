# Odin Training Site

This is a small training site for practicing HTML, CSS, JavaScript, Git, GitHub, and GitHub Pages.

The example site is about Cosmo, my rescue dog.

## Live site

GitHub Pages URL: https://bhurst.me/odin-training-site/

## Training notes

This repo is intentionally simple.

The goal is to practice small, understandable commits.

This iteration adds CSS foundations with one external stylesheet. The styles
practice type selectors, class selectors, the cascade, readable spacing, the box
model, and the difference between block and inline elements.

GitHub Pages can be used to preview the site in a browser.

Future weeks will add layout and JavaScript.
